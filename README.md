# AI-ANC-Defense

Upload a noisy audio file (gunshots, helicopter rotor, artillery, vehicle engine, sirens
mixed with speech) and get clean, intelligible speech back. Standalone app + the
fine-tuning pipeline that specializes the model on military noise.

## 1. How the pieces fit together

```
ai-anc-defense/
  requirements.txt
  data/
    clean/            <- VCTK clean speech goes here
    noise_military/   <- MAD (military audio dataset) noise clips go here
    noise_urban/      <- UrbanSound8K noise clips go here
    processed/         <- auto-generated by prepare_data.py (train/val mixes)
  scripts/
    prepare_data.py    <- mixes clean speech + noise into noisy/clean training pairs
    train.py            <- fine-tunes the pretrained model on your mixes
    evaluate.py          <- prints SNR/STOI/PESQ numbers on a held-out set
  app/
    infer.py             <- shared inference code (loads model, runs it)
    app.py                <- the Streamlit upload-and-listen interface
  models/
    finetuned_military.pth  <- created by train.py (the app auto-uses this if present)
```

You can use the **app immediately** with the general pretrained model (Step 2), and
add the **fine-tuning** (Steps 3-5) afterwards to specialise it on military noise —
the app automatically switches to the fine-tuned model once it exists.

## 2. Quick start — run the interface right now (no training required)

```bash
git clone https://github.com/queen0642/AI-ANC-Defense.git
cd AI-ANC-Defense
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt

streamlit run app/app.py
```

This opens a browser tab at `http://localhost:8501`. Upload any noisy speech
clip and you'll see/hear the before-and-after immediately, using Facebook's
general-purpose pretrained denoiser. This already works reasonably well on
many noise types — fine-tuning below makes it noticeably better specifically
on gunshots/helicopters/artillery.

## 3. Download and lay out the datasets

### 3.1 Clean speech — VCTK

Easiest path is via `torchaudio`, which downloads and extracts VCTK for you:

```python
import torchaudio
torchaudio.datasets.VCTK_092(root="vctk_raw", download=True)
```

Then copy a subset of the .wav files (any speakers) into `data/clean/`:

```bash
mkdir -p data/clean
find vctk_raw -name "*.wav" | head -3000 | xargs -I{} cp {} data/clean/
```

(You don't need all ~44,000 VCTK files — a few thousand is enough for
fine-tuning purposes.)

### 3.2 Military noise — MAD dataset (Kaggle)

1. Go to the dataset page and download it (Kaggle requires a free account):
   https://www.kaggle.com/datasets/wimccall/reduced-mad-dataset-military-audio-dataset
2. Or use the Kaggle CLI:

```bash
pip install kaggle
# place your kaggle.json API token in ~/.kaggle/kaggle.json first
kaggle datasets download -d wimccall/reduced-mad-dataset-military-audio-dataset -p data_raw --unzip
```

3. Copy every clip into a flat folder:

```bash
mkdir -p data/noise_military
find data_raw -iname "*.wav" -exec cp {} data/noise_military/ \;
```

### 3.3 Urban/general noise — UrbanSound8K (Kaggle)

```bash
kaggle datasets download -d chrisfilo/urbansound8k -p data_raw_urban --unzip
mkdir -p data/noise_urban
find data_raw_urban -iname "*.wav" -exec cp {} data/noise_urban/ \;
```

UrbanSound8K is mixed in at a lower ratio (default 30% of mixes) purely so the
model doesn't over-specialise and lose general robustness — the majority of
training mixes (70% by default) use military noise, which is the actual point
of this project.

## 4. Build the noisy/clean training pairs

```bash
python scripts/prepare_data.py --n_train 1500 --n_val 200 --military_ratio 0.7
```

This randomly pairs speech clips with noise clips at SNRs between -5 dB and
+15 dB and writes matched noisy/clean `.wav` pairs into
`data/processed/train/` and `data/processed/val/`. Increase `--n_train` if you
have time and want a stronger fine-tune (more pairs = better generalisation,
longer to build and train).

## 5. Fine-tune the model

You can do this locally (slow without a GPU) or for free on Google Colab
(recommended — a T4 GPU finishes this in minutes, not hours).

### Option A — locally

```bash
python scripts/train.py --epochs 5 --batch_size 4 --lr 1e-5 \
    --data_dir data/processed --out models/finetuned_military.pth
```

### Option B — Google Colab (free GPU)

1. Open https://colab.research.google.com/ and create a new notebook.
2. `Runtime > Change runtime type > GPU (T4) > Save`.
3. Upload your `data/processed` folder (zip it first) or mount Google Drive.
4. Run:

```python
!pip install torch torchaudio denoiser soundfile tqdm
!git clone https://github.com/queen0642/AI-ANC-Defense.git
%cd AI-ANC-Defense
# unzip your data/processed into place here, then:
!python scripts/train.py --epochs 5 --batch_size 8 --lr 1e-5 \
    --data_dir data/processed --out models/finetuned_military.pth
```

5. Download `models/finetuned_military.pth` from the Colab file panel and put
   it in your local `models/` folder — the Streamlit app auto-detects it.

Training loss is **negative SI-SNR** (lower is better). Watch the printed
`val SI-SNR loss` each epoch and stop once it stops improving — you are
nudging a pretrained model, not training from scratch, so 3-5 epochs on a
few thousand pairs is typically enough.

## 6. Check how much it actually improved

```bash
python scripts/evaluate.py --data_dir data/processed/val --use_finetuned --limit 100
```

Prints average SNR, STOI, and PESQ before vs. after on your held-out
validation pairs — this is the evidence for your results slide, and directly
answers the judge question "what were your measured results?" from Document 1.

## 7. Run the app with the fine-tuned model

```bash
streamlit run app/app.py
```

Nothing changes about how you run it — `app/infer.py` automatically checks
whether `models/finetuned_military.pth` exists and loads it instead of the
generic pretrained model. The app's info banner at the top confirms which
model is active.

## 9. Common problems

| Problem | Fix |
|---|---|
| `streamlit: command not found` | Activate your virtual environment first (`source venv/bin/activate`) |
| Denoiser model download fails on first run | It downloads a ~50MB checkpoint from the internet the first time `pretrained.dns64()` is called — check your connection/firewall |
| `pesq` fails to install | Needs a C++ compiler — on Windows install "Microsoft C++ Build Tools" first; on Linux `sudo apt install build-essential` |
| Training is extremely slow | You're on CPU — use Google Colab's free GPU (Section 5, Option B) instead |
| App shows "general pretrained model" even after training | Confirm `models/finetuned_military.pth` actually exists at that exact path relative to the project root |
| Uploaded file plays but sounds unchanged | Very high input SNR (already fairly clean) can look/sound like a small change — check the spectrogram panel and the "noise energy reduced" metric, both make small improvements visible even when subtle by ear |
